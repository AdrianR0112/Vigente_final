# Vigente Dashboard Integrador

Sitio estatico para consultar los cuatro modulos del proyecto final de Emprendimiento y Legislacion Laboral.

## Uso

Abra `index.html` en un navegador moderno. No requiere instalacion, servidor ni conexion a internet.

## Contenido

- `index.html`: estructura semantica de la aplicacion.
- `styles.css`: identidad visual y adaptacion responsive.
- `data.js`: datos academicos y resultados simulados.
- `app.js`: navegacion, filtros, pestanas, visor documental e impresion.
- `assets/docs/`: documentos de respaldo.
- `output/Informe_Corporativo_Vigente.pdf`: informe final de ocho paginas.

Los casos de IVA y liquidacion son simulaciones academicas y no sustituyen calculos oficiales.
